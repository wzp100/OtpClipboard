## 可直接发布的正文

电脑登录，验证码发到手机上。
拿起手机、看一眼、记住数字，再切回电脑输入……这一步每天都在重复。

所以我做了「验证码剪贴板」📋

手机收到验证码，只要“手机连接”把通知送到 Windows 通知中心，小工具就会在本机识别，自动复制到剪贴板。
回到输入框，Ctrl + V 就行。也会在光标旁弹个小提示，点一下填入。

几个我在意的小细节：
✨ 支持 4–8 位数字验证码，中英文关键词都能识别
✨ 关掉主界面后，后台继续监听；再次打开时界面按需启动
✨ 可以收起到托盘，按 Ctrl + Alt + O 唤回，并支持开机自动启动
✨ 应用本身不联网，识别在本机完成
✨ 验证码和通知正文不写入历史文件，重启只保留处理状态和时间
✨ 写入剪贴板时，单次操作关闭 Windows 剪贴板历史与跨设备同步选项

使用前需要完成“手机连接”配对和通知共享，再给小工具授予通知访问权限。
主要围绕 iPhone + Windows 的使用场景制作，实际能否收到通知取决于“手机连接”的支持情况。特殊输入框可以手动 Ctrl + V。

v1.0.5 修正了主界面偶发空白，也整理了隐藏浮窗重绘和后台消息循环。开发机 30 秒空闲采样平均 CPU 是 0.00%，这里仅作为本次回归结果，不代表每台设备都完全一样。
