## 可直接发布的正文

电脑登录，验证码发到手机上。
拿起手机、看一眼、记住数字，再切回电脑输入……这一步每天都在重复。

所以我做了「验证码剪贴板」📋

手机收到验证码，只要“手机连接”把通知送到 Windows 通知中心，小工具就会在本机识别，自动复制到剪贴板。
回到输入框，Ctrl + V 就行。也会在光标旁弹个小提示，点一下填入。

几个我在意的小细节：
✨ 支持 4–8 位数字验证码，中英文关键词都能识别
✨ 可以收起到托盘，支持开机自动启动
✨ 应用本身不联网，识别在本机完成
✨ 验证码和通知正文不写入历史文件，重启只保留处理状态和时间
✨ 写入剪贴板时关闭 Windows 的历史记录和跨设备同步选项

使用前需要完成“手机连接”配对和通知共享，再给小工具授予通知访问权限。
目前围绕 iPhone + Windows 的使用场景制作，实际能否收到通知取决于“手机连接”的支持情况。特殊输入框可以手动 Ctrl + V。

项目：OtpClipboard
GitHub：https://github.com/wzp100/OtpClipboard
安装包以仓库 Releases 的实际内容为准；没有安装包时可按 README 从源码运行。

如果你也经常在电脑和手机之间来回抄验证码，可以试试这个小工具。
