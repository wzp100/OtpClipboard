# 验证码剪贴板 v1.0.4

Windows x64 安装包已重新构建，包版本为 **1.0.4.0**，包含本次代码整理与隐私修复。

## 下载与安装

下载附件 **OtpClipboard-1.0.4.0-Setup.exe**，双击运行。安装程序包含应用 MSIX、Windows App Runtime 和安装所需的公钥证书。

- 适用于 Windows x64；手机通知转发还需满足微软“手机连接”的系统与手机要求。
- 首次使用需完成手机连接配对、通知共享，并允许应用访问通知。
- 安装程序使用自签名 MSIX 证书，需要管理员权限导入“本地计算机 → 受信任人”。安装 EXE 没有商业代码签名，Windows 可能显示未知发布者提示，请先核对下载来源。
- `SHA256SUMS.txt` 提供安装文件的完整性校验值。可用 `Get-FileHash -Algorithm SHA256 .\OtpClipboard-1.0.4.0-Setup.exe` 核对。

## 本版变化

- 新界面、托盘、开机自启动和验证码浮窗，支持 Ctrl + Alt + O 唤回窗口。
- 验证码、通知标题与正文不再写入应用历史文件，重启后只恢复处理状态与时间。
- 成功读取旧历史时立即脱敏重写；旧记录的验证码不再支持重启后重新复制。
- 剪贴板写入不加入 Windows 历史、不跨设备漫游；默认先过滤通知来源，再读取正文。
- 拆分历史记录模块，完善 README、开发文档和回归测试，并加入发布文件隐私检查。
- Release 编译移除本机源码路径和调试信息，安装包不附带本地调试符号或用户数据。

应用不会自动清除当前剪贴板，第三方剪贴板管理器仍可能读取其内容。详细说明见仓库 README 和 SECURITY.md。

卸载请使用 Windows“设置 → 应用 → 已安装的应用”。
