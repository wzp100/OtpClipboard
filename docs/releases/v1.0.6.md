# v1.0.6

这是一次针对窗口拖动顿挫的稳定性更新。

## 主要变化

- **修复拖动卡顿**：UI 原先每秒新建命名管道连接检查后台存活，会周期性唤醒 UI 与后台线程。现在改为阻塞等待后台持有的命名互斥量，不再定时轮询。
- **保留退出联动**：后台进程退出时，系统会立即唤醒 UI 并关闭窗口，不会留下孤立界面。
- **继续沿用 v1.0.5 的修复**：主界面空白、隐藏浮窗持续重绘、后台消息循环与线程调度修复全部保留。

## 隐私

通知正文和验证码只存在于当前后台运行进程的内存。磁盘历史仅保留最近 200 条处理状态和时间；应用没有联网功能或远端识别服务。当前剪贴板由 Windows 与第三方剪贴板工具分别管理，退出应用不会代为清空。
