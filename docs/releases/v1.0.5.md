# v1.0.5

这是一次围绕稳定性、后台占用和维护性的更新。

## 主要变化

- **修复主界面空白**：后台状态改由当前用户命名管道提供给按需 UI，不再跨进程携带 WinUI 对象。
- **修复后台 CPU 空转**：隐藏浮窗现在会完整消费重绘区域；后台原生消息泵会先分发已排队消息，再等待新事件。
- **关闭界面后更轻**：关闭主窗口会退出 UI 进程并释放 WinUI 资源，后台通知监听、托盘和快捷键继续工作。
- **线程边界更清楚**：通知回调、管道命令和异步续体统一回到后台 STA；开机自启动也由后台处理。
- **减少维护隐患**：移除重复状态色字典、未使用桥接类型与旧字段，文档同步当前进程结构。

## 隐私

通知正文和验证码只存在于当前后台运行进程的内存。磁盘历史仅保留最近 200 条处理状态和时间；应用没有联网功能或远端识别服务。当前剪贴板由 Windows 与第三方剪贴板工具分别管理，退出应用不会代为清空。
