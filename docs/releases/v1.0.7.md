# v1.0.7

这是一次针对窗口拖动流畅度的修复更新。v1.0.6 降低了周期性后台唤醒，但正式版仍使用 WinUI 自定义标题栏，没有消除拖动时的主要掉帧来源。

## 主要变化

- **改用 Windows 原生标题栏**：移除 `ExtendsContentIntoTitleBar` 和 WinUI 自定义 `TitleBar`，避免拖动窗口时标题栏重复参与布局、重绘和合成。
- **保留 Mica 背景**：窗口标题、图标和系统背景材质仍然保留。
- **保留后台存活检测修复**：UI 阻塞等待后台互斥量，仅在后台退出时唤醒，不再每秒创建命名管道。
- **继续沿用 v1.0.5 的修复**：主界面空白、隐藏浮窗持续重绘、后台消息循环与线程调度修复全部保留。

## 对照结果

| 窗口配置 | 30 次移动平均耗时 | 最大耗时 |
| --- | ---: | ---: |
| v1.0.6 自定义 WinUI 标题栏 | 约 39 ms | 约 59 ms |
| 关闭 Mica，仍使用自定义标题栏 | 约 40 ms | 未改善 |
| v1.0.7 Windows 原生标题栏（正式安装包） | 5.59 ms | 11.4 ms |

本机测试中，v1.0.7 的所有移动样本均低于 16 ms。数据来自具有双显卡和 150% 缩放环境的一台开发机，仅用于说明本次修复，不承诺所有设备、显示器或通知负载下完全一致。

## 隐私

通知正文和验证码只存在于当前后台运行进程的内存。磁盘历史仅保留最近 200 条处理状态和时间；应用没有联网功能或远端识别服务。当前剪贴板由 Windows 与第三方剪贴板工具分别管理，退出应用不会代为清空。
